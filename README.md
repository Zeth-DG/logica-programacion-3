# Práctica de lógica de programación #3 - Factorial (JS con DOM)

Este repositorio contiene la solución al ejercicio de lógica de programación número 3, adaptado para recibir entradas del usuario mediante un campo de texto (`input`) en el DOM y mostrar los resultados directamente en la interfaz web.

## Descripción del programa

El programa realiza las siguientes tareas:
1. **Entrada de datos:** Captura el número ingresado por el usuario desde un elemento `<input>` en el DOM.
2. **Validación:** Comprueba si el dato introducido es un número válido. Si está vacío o contiene caracteres incorrectos, muestra un mensaje de error en pantalla.
3. **Cálculo:** Calcula el factorial del número ingresado.
4. **Salida:** Imprime el resultado dinámicamente en la página web.

## Casos de prueba

El programa fue probado y verificado con los siguientes casos de éxito:

| Entrada ($n$) | Salida Esperada ($n!$) | Estado |
| :---: | :---: | :---: |
| `5` | `120` | ✅ Aprobado |
| `6` | `720` | ✅ Aprobado |

## Cómo ejecutar el proyecto

1. Clona este repositorio:
   ```bash
   git clone [https://github.com/tu-usuario/logica-programacion-3.git](https://github.com/tu-usuario/logica-programacion-3.git)
    ```
2. Abre el archivo index.html en tu navegador web o utiliza una extensión como Live Server en VS Code.
3. Interactúa con el prompt que aparecerá en pantalla: ingresa un número en el campo de texto y haz clic en Enviar.

## Validaciones incluidas
- No acepta campos vacíos
- No acepta números negativos, ni decimales
